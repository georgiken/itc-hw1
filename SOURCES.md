# SOURCES

## Системы генерации кода

1. **DeepSeek** (chat.deepseek.com): первоначальный черновик решения — общая
   структура CLI, класс источника, черновики задач 1.2 и 1.3. От черновика
   отказались (см. «Журнал неудач» в REPORT.md); в итоговом коде его фрагментов нет.
2. **Claude** (Anthropic, Opus 5.5, режим Cowork): написание и отладка итогового кода и
   документов по шагам, отражённым в истории коммитов (трейлер `Co-Authored-By`):
   * `itc/probs.py`, `itc/source.py`, `itc/cli_t1.py` — разбор формата, точная выборка,
     прямой проход для вероятностей, расширенный формат;
   * `itc/uniform.py`, `itc/cli_t2.py` — проверка источника, перебор типов, точный l(n);
   * `itc/huffman.py`, `itc/crc32.py`, `itc/zmh.py`, `itc/stats.py`, `itc/cli_t3.py` — архиватор;
   * `main.py`, `run_tests.py`, `tests/selfcheck.py`, тестовые описания источников;
   * `SPEC.md`, `REPORT.md`, `README.md`.

   Каждый файл кода размечен комментариями начала и конца сгенерированного фрагмента.

## Прочее

* Документация Python 3 (`fractions`, `heapq`, `struct`, `argparse`, `random`).
* Материалы курса «Теория информации и кодирования», недели 1–5 (энтропия, теоремы
  равномерного кодирования, код Хаффмана, неравенство Крафта).
* Полином CRC-32 — IEEE 802.3 (0xEDB88320, отражённая форма); `zlib.crc32` используется
  только в самопроверке.
