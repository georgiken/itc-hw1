# Расширенный формат описания источника

Файл — JSON. Расширение обратно совместимо: любой файл исходного формата
(`models` / `switches` / `source`) является корректным файлом расширенного
формата и читается без конвертации.

## Грамматика

```
файл        := компонента | смесь
смесь       := { "mixture": [ элемент, ... ] }              // непустой список
элемент     := { "weight": вероятность, "source": компонента }
компонента  := { "models":   { имя: модель, ... },
                 "switches": { имя: { имя_модели: вероятность, ... }, ... },
                 "source":   [ имя_переключателя, ... ] }   // непустой
модель      := распределение                                 // без памяти (исходный формат)
             | { "order": d, "contexts": { контекст: распределение, ... } }   // марковская
распределение := { символ: вероятность, ... }                // сумма = 1
контекст    := ""  |  "x1,x2,...,xj"     (1 <= j <= d)       // символы через запятую
вероятность := строка: обыкновенная дробь "p/q" или десятичная запись "0.25"
```

Ограничения: все вероятности неотрицательны, каждое распределение и набор весов
`mixture` нормированы ровно к 1 (проверяется в рациональной арифметике);
переключатели ссылаются только на существующие модели, `source` — только на
существующие переключатели; вложенная смесь запрещена; марковская модель обязана
задать распределение для **каждого** контекста длины 0..d над алфавитом компоненты.

## Семантика

* **Компонента.** На такте `t` (с нуля) берётся переключатель `source[t mod L]`,
  по нему выбирается модель, по модели — символ. Модель без памяти выдаёт символ
  по своему распределению. Марковская модель глубины `d` смотрит на последние
  `min(t, d)` выданных символов (контекст) и выдаёт символ по распределению
  `contexts[контекст]`; контексты короче `d` задают начальный участок.
  Предыстория общая для всех моделей компоненты.
* **Смесь.** Перед первым тактом **один раз** выбирается компонента с вероятностью
  `weight`, дальше вся реализация порождается только ею. Вероятность любого блока
  есть `Σ weight_c · Pr_c(блок)`.
* Глубина памяти источника — максимальный `order` его моделей (в варианте `d = 1`).

## Почему в исходном формате неэргодический источник невыразим

В исходном формате выборы на разных тактах независимы, то есть `X_1, X_2, ...` —
независимые величины. Если источник при этом стационарен, распределение всех
тактов одинаково, и последовательность i.i.d. По усиленному закону больших чисел
частота любого блока почти наверное сходится к его вероятности — источник
эргодичен. Значит, неэргодичность требует зависимости между тактами, причём
«бесконечно долгой»: случайного параметра, который выбирается один раз и не
забывается. Это и есть конструкция `mixture`.

## Примеры (k = 5, M = 2, L = 4; файлы в `tests/t1/`)

| файл | стационарный | эргодический | что обеспечивает свойство |
|---|---|---|---|
| `ext_stationary_iid.json` | да | да | все переключатели задают одну смесь моделей (3/5, 2/5) ⇒ одинаковое распределение на каждом такте, такты независимы |
| `variant.json` | нет | — | переключатели s1..s4 разные ⇒ распределение зависит от `t mod 4` (периодически нестационарный) |
| `ext_markov_ergodic.json` | да | да | марковская модель `C` порядка 1 с циклической матрицей, все переходы > 0 (неприводимость, апериодичность); матрица дважды стохастическая, поэтому равномерное начальное распределение `""` стационарно |
| `ext_nonergodic_mixture.json` | да | нет | `mixture` из двух стационарных i.i.d. компонент с весами 1/2: компонента выбирается один раз, частота `a` сходится к 0,34 или к 0,125 в зависимости от реализации, а не к Pr{a} = 93/400 |

Фрагмент марковской модели (`ext_markov_ergodic.json`):

```json
"C": {"order": 1, "contexts": {
  "":  {"a": "1/5", "b": "1/5", "c": "1/5", "d": "1/5", "e": "1/5"},
  "a": {"a": "1/2", "b": "1/4", "c": "1/8", "d": "1/16", "e": "1/16"},
  "b": {"b": "1/2", "c": "1/4", "d": "1/8", "e": "1/16", "a": "1/16"},
  ...
}}
```

Смесь (`ext_nonergodic_mixture.json`):

```json
{"mixture": [
  {"weight": "1/2", "source": { "models": {...}, "switches": {...}, "source": [...] }},
  {"weight": "1/2", "source": { ... }}
]}
```
